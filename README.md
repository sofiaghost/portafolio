## Características

- Bilingüe, español e inglés, con selector de idioma.
- Modo claro y oscuro: respeta la preferencia del sistema y permite cambiarla.
- Animaciones al hacer scroll, que se desactivan si el sistema pide reducir el movimiento.
- Diseño responsive para móvil, tablet y escritorio.
- Sin dependencias: HTML, CSS y JavaScript nativos en un solo archivo.

## English

Personal portfolio of **Laura Sofía Vallejo**, a Systems Engineering student interested in development and design. It's aimed at internships and my first job.

**Features:** bilingual (ES/EN), light and dark mode, scroll animations that respect reduced-motion settings, a responsive layout, and no dependencies (a single HTML file).

**Run locally:** open `index.html` in a browser or run `python -m http.server 8000`.

**Deploy:** push to a repository named `sofiaghost.github.io`, then enable GitHub Pages from the `main` branch.
